# Product

## Register

product

## Users

Developers, operators, and AI coding agents who work across SSH sessions, SFTP transfers, tunnels, local shells, and remote command workflows. They use VibeShell while deploying, inspecting logs, moving files, recording sessions, and handing context between human and agent work.

## Product Purpose

VibeShell gives terminal-first remote work a native, observable workspace. Success means a user can connect to the right machine quickly, see session state at a glance, move between terminal, files, tunnels, snippets, and settings without losing context, and let AI tools act through the same visible workspace.

## Brand Personality

Focused, technical, sharp. The interface should feel like a serious command center: dense enough for real work, polished enough to trust, and energetic without getting in the way of terminal flow.

## Anti-references

Avoid marketing-page drama inside the app, decorative card grids, novelty terminal effects, over-bright cyberpunk color, glass-heavy panels, oversized rounded controls, and generic gray UI that ignores the Tokyo Night identity.

## Design Principles

- Keep the terminal as the primary surface.
- Make connection state readable before the user has to ask.
- Use accent color for intent and state, not decoration.
- Preserve dense workflows while improving scan speed.
- Let AI integration feel native to the workspace rather than bolted on.

## Accessibility & Inclusion

Target WCAG AA contrast for product text and controls. Keep focus states visible for keyboard users, avoid motion that delays interaction, and respect reduced-motion preferences.
